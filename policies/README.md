# Policy Set

This folder is intended to hold lightweight policy templates or policy outlines for a zero-cost ISMS.

## Suggested Policy Set

| Policy / Procedure | Purpose |
|---|---|
| Information Security Policy | Sets overall security direction and management intent |
| Acceptable Use Policy | Defines acceptable use of organizational systems and data |
| Access Control Procedure | Defines account creation, access review, and removal practices |
| Incident Response Procedure | Defines escalation, triage, response, and reporting process |
| Vendor Security Procedure | Defines vendor due diligence and risk review process |
| Data Classification Guideline | Defines information sensitivity levels and handling expectations |
| Backup and Recovery Procedure | Defines backup scope, frequency, testing, and ownership |
| Change Management Procedure | Defines how system and process changes are reviewed and approved |

## Minimum Policy Template

Each policy should include:

- Purpose
- Scope
- Roles and responsibilities
- Requirements
- Exceptions
- Review frequency
- Approval owner
- Version history

## Notes

Start with short and usable policies. A simple policy that people understand and follow is better than a long policy that is ignored.
